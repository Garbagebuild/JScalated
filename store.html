OStore

Install on your KaiOS 3 phone

  1. Choose Install OStore on the JScalated home page.
  2. When the blank System page opens, enter the two address-bar commands shown on the home page.
  3. The installer connects to AppsManager and installs OStore. Open it from the phone's app list.
  4. OStore loads apps from https://Garbagebuild.github.io/JScalated-Store/webapps.json catalogue and the OStore API.

How the GitHub catalogue is published

Each app has a stable folder beneath Apps-directory/. The folder includes manifest.webmanifest, update.webmanifest, and a 56 × 56 icon beside the update manifest. The update manifest points AppsManager to the ZIP on GitHub Releases. The root webapps.json lists the app folders.

Package-signature limit

The supplied Python tool copies signing-container metadata from a signed example, but its output is not cryptographically signed by the example's author. On affected firmware AppsManager may accept it; other devices may reject it with INVALID_SIGNATURE. Only install packages you trust. Installation and AppsManager access need to be confirmed on your phone.
