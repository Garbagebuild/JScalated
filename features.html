Features & safety

JScalated ADB method

  • Complete loader carried through window.name to the System page
  • One XPI installs the matching public key and enables USB ADB, with optional wireless ADB on port 5555
  • The parent add-on checks and restores ADB settings at each later startup
  • An optional checkbox stages the WebIDE debugger preferences in user.js
  • The on-phone panel shows staging errors and startup logs

Preinstalled apps and remote shell

The built-in AppsManager panel can disable and restore registered apps; protected phone components are blocked. The advanced agent control downloads api_agent_api23 from a user-run LAN server that sends CORS headers, then the parent XPI copies it to its target, sets executable mode, and starts it after the next phone reboot. See the agent setup guide.

OStore

  • Installs through the AppsManager service
  • Reads the JScalated GitHub catalogue and the OStore API
  • Shows install and update results on the phone

Package-signature limit: the supplied local package tool produces invalid CMS signatures. Device acceptance is not proof of authenticity. Review and trust packages independently before installing them.

Shared ADB key

This method uses one public computer key pair so a KaiOS keypad user never has to type a long key. The matching computer private key is intentionally shared with everyone who downloads the bundle.
