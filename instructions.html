ADB setup guide

1. Load JScalated

Open this site on the phone and press Load JScalated. The page places the complete loader in window.name and opens the blank System page in the same tab. The System page does not need to fetch a remote JavaScript file.

2. Open the panel

On the blank System page, enter these address-bar commands in order:

javascript:document.createElement('script')javascript:document.write(name)

Keep the same tab between the two commands. If the panel does not appear, return to the landing page and press Load JScalated again.

3. Enable ADB

Choose Enable WebIDE debugger if you want the Firefox debugger. Choose Enable wireless ADB on port 5555 if you want Wi-Fi access. Press Enable ADB. The log box directly below the button reports whether the XPI, profile preferences, and request were staged and read back.

After staging completes, turn the whole phone off and back on. Reloading the browser page is not a reboot. The XPI installs the matching ADB key, enables ADB, and checks the service on later phone boots. You do not need to reopen the System page to activate ADB.

4. Connect from a computer

Download the matching computer ADB key bundle on the computer. Extract its files beside adb.exe in Android platform-tools. For wireless ADB, run:

connect-jscalated.cmd PHONE_WIFI_IP

The command file starts the normal ADB server with the matching key, connects to port 5555, and opens a shell. After it connects, ordinary adb devices and adb shell commands use that server until it stops.

WebIDE debugger

If you selected the debugger checkbox, run this on the connected computer after the phone reboots:

adb forward tcp:6000 localfilesystem:/data/local/firefox-debugger-socket

Then open WebIDE in a compatible desktop browser. See the KaiOS.dev guide.

Other tools

The app manager below ADB uses KaiOS AppsManager to disable or restore registered preinstalled apps. System and Homescreen are protected. The advanced remote shell control at the bottom downloads a prebuilt agent from your LAN server and stages it for the next full phone reboot. Build and run the server using the agent setup guide.

If ADB does not connect

Reopen JScalated on the phone, repeat the two System-page commands, then press View activation log (optional). The log shows the first activation and the latest boot check. A success logo appears only when the on-device check passes. A TCL Flip 3 T435X tester connected successfully and reconnected after a second phone reboot; other builds may behave differently.
